# PM Brawler — Projekťák: Termín byl včera

A funny 2D beat 'em up platformer made in Unity. You play a project manager fighting your way
up the org chart: developers → testers → stakeholders → the Steering Committee → the C-suite.
Czech and English text (Tab switches the language), built for WebGL.

## Getting started

1. Install **Unity Hub** (https://unity.com/download) and a **Unity 6 LTS** editor (6000.0.x)
   with the **WebGL Build Support** module.
2. Unity Hub → **Add → Add project from disk** → select this folder (`~/code/PM-Brawler`).
   If Hub says the editor version differs, choose your installed Unity 6 version.
3. On first open the project creates `Assets/Scenes/Main.unity` by itself.
   Press **Play**. (If the scene isn't there, use the menu **PM Brawler → Create Main Scene**.)

There is nothing to set up in the scene: `GameManager` bootstraps itself and builds the levels,
characters and HUD from code, using the pixel art in `Assets/Resources/Art`.

## Controls

| Action | Keys |
|---|---|
| Move | A / D or ← / → |
| Jump (hold for higher) | Space / W / ↑ |
| Drop through a desk | S + Space |
| Attack (3-hit combo, air attack) | J or X |
| Gantt slam (heavy, breaks shields) | K or C |
| "Let's take this offline" (stuns everyone nearby, costs 50 caffeine) | L or V |
| Pause | Esc or P |
| Language CZ/EN | Tab |
| Fullscreen on/off | F |
| Switch graphics (hand-drawn / pixel art) | G |

On phones and tablets (landscape) the game shows touch buttons instead: a d-pad on the left, jump, hit,
Gantt slam and "take this offline" (the coffee) on the right, and pause / fullscreen / language at the top.
Tap anywhere to get through menus. `TouchControls.cs` draws them and feeds `GameInput`.

## The cast

| Enemy | Gimmick |
|---|---|
| Developer | Raises a "works on my machine" shield that blocks light hits from the front. Slam it or hit them from behind. |
| Tester | Keeps their distance, throws BUG reports that slow you down. |
| Stakeholder | Shouts "Scope creep!" and charges. Dodge, then punish while they catch their breath. |
| CFO | Throws budget cuts that drain your caffeine. |
| **Steering Committee** (boss) | Meeting invites, escalations that summon stakeholders, status-report table slam. |
| **CEO** (final boss) | Synergy dash, memos; under 50 % HP pivots (reverses your controls), launches strategic initiatives (summons developers) and shockwave slams. |

Pickups: **coffee** (health + caffeine), **Gantt chart** (2× damage for 12 s), **scope freeze** (freezes enemies).
The exit stays locked until every blocker in the level is defeated ("awaiting sign-off").

## Code map

- `Assets/Scripts/Core` — `GameManager` (state machine, HUD, level loading), `Loc` (CZ/EN texts),
  `GameInput` (works with both input systems), `Art` (loads sprites, character sheets, text), `Fx`,
  `CameraFollow` (pixel-perfect zoom; `ViewHeight` sets how much of the level is visible), `Parallax`
- `Assets/Scripts/Combat` — `Fighter` (shared physics/hit logic), `Health`, `Projectile`
- `Assets/Scripts/Player/PlayerController.cs`
- `Assets/Scripts/Enemies` — `Enemy` base class plus one file per enemy type
- `Assets/Scripts/Level` — `Levels.cs` (text maps), `LevelBuilder`, `Pickup`, `ExitDoor`
- `Assets/Editor/ProjectSetup.cs` — scene setup and the **PM Brawler → Build WebGL** menu

### Adding content

- **Edit a level:** change the text map in `Levels.cs` (legend at the top of the file).
- **New text / translation:** add a key to the table in `Loc.cs` with both Czech and English.
- **New enemy:** subclass `Enemy` (or `Thrower` for ranged), set stats and look in `Configure()`,
  override `Think()` / `Attack()`, and give it a letter in `LevelBuilder.Build`.
- **Art:** see below.

## Art

The game has two art styles with the same layout, switchable in game with **G** (or the ART button on
touch screens); the choice is remembered:

- **Hand-drawn** (default) in the spirit of Deponia-style adventures: inked outlines, painted shading, big
  lanky characters and offices full of project-management clutter (Kanban boards, Gantt charts, burndowns,
  risk matrices, RAG status boards, a KPI dashboard...). Generated by `Tools/ArtGenHD` (Skia) into
  `Assets/Resources/ArtHD`, 128 px per unit, camera showing about 7 units.
- **Pixel art** in the style of Monkey Island / Simon the Sorcerer, generated by `Tools/ArtGen` into
  `Assets/Resources/Art`, 32 px per unit with a pixel-perfect camera.

Regenerate either style:

```
python3 -m venv Tools/ArtGen/.venv && Tools/ArtGen/.venv/bin/pip install pillow numpy skia-python
Tools/ArtGen/.venv/bin/python Tools/ArtGenHD/gen_art_hd.py   # hand-drawn
Tools/ArtGen/.venv/bin/python Tools/ArtGen/gen_art.py        # pixel art
```

- `characters.py` / `characters_hd.py` — the posable figure and each character's outfit (`CAST`), plus the
  Steering Committee. Both styles share the animation poses and frames (`idle0/1`, `walk0-3`, `jump`, `fall`,
  `atk0` wind-up, `atk1` strike, `hurt`).
- `environment.py` / `environment_hd.py` — per-level themes (`THEMES`): the view through the windows, the
  wall, floor tiles, props, pickups, the exit door, thrown papers and effects.
- Each style's `manifest.json` tells the game its scale, camera zoom, font, room geometry and which props go
  on the walls and floors. `Assets/Editor/PixelArtImporter.cs` imports pixel art crisp and uncompressed, and
  hand-drawn art smooth, mipmapped and crunch-compressed.

In game, `Fighter` picks the animation frame from its state; call `Pose("atk0", seconds)` to hold a frame.
Text uses Kalam (hand-drawn) or Pixelify Sans (pixel), both SIL Open Font License, in `Assets/Resources/Fonts`.

## Publishing on the web

The game is playable at **https://miroslavkrupa.github.io/pm-brawler/**, served by GitHub Pages from the
`gh-pages` branch. To publish a new version, close the project in Unity and run:

```
Tools/publish_web.sh            # build WebGL, then push it to gh-pages
Tools/publish_web.sh --no-build # push the existing Builds/WebGL
```

The site updates a minute or two after the push. **PM Brawler → Build WebGL** in the editor makes the same
uncompressed build in `Builds/WebGL`; it works on any static host.
